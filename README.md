🏠 Housing Data Exploration & Visualization Project

Major Project – Elewayte Internship

📌 Project Overview

This project performs Exploratory Data Analysis (EDA) and visualization on a real-world housing.csv dataset.
The goal is to understand housing price patterns, compare feature-based prices, and analyze relations between different property attributes.

This project was developed as part of the Elewayte Major Project.

📂 Dataset

File: housing.csv
Contains housing attributes such as:

• Price

• Area (sqft)

• Parking

• AC / Non-AC

• Preferred Area

And more…

🎯 Project Tasks 

1️⃣ Price Range Distribution

Categorized houses into price ranges:
0–25 lakhs,
26–50 lakhs,
51–75 lakhs,
76–100 lakhs &
100 lakhs

🔹 Plotted using a Line Chart

2️⃣ AC vs Non-AC Average Prices

Calculated average house price for:

✔ AC houses

✔ Non-AC houses

🔹 Visualized using a Bar Chart

3️⃣ Parking vs House Price Relationship

• Simulated and analyzed how parking availability affects house prices

• Visualized using scatter plot and descriptive statistics

4️⃣ Price Gap Analysis

Compared price difference between:

• Houses with < 5000 sqft & No Preferred Area

• Houses with > 5000 sqft & Preferred Area
